# 体重ログ（PWA 一式）

## 中身
- index.html … アプリ本体（記録・グラフ・履歴・CSV入出力、データは端末内に保存）
- manifest.json / sw.js … ホーム画面への追加とオフライン動作に必要
- privacy.html … プライバシーポリシー（連絡先メールの記入が必要）
- icons/ … アイコン（192px, 512px, maskable 512px）

## 1. まず動かす（ストア公開の前に）
1. GitHub で無料のリポジトリを作り、このフォルダの中身をアップロードする。
2. Settings → Pages で公開する（https://ユーザー名.github.io/リポジトリ名/ になる）。
3. スマホの Chrome でそのURLを開き、メニューの「ホーム画面に追加」または「アプリをインストール」。
   これだけでも、アプリのように使えます。

## 2. Google Play に出す手順
1. **privacy.html の連絡先を書き換える**（【ここに…】の部分）。
2. https://www.pwabuilder.com にPages のURLを入力 → Android のパッケージを生成（Play Store 用の AAB）。
   - Package ID 例: com.あなたの名前.weightlog （一度公開すると変更できません）
   - 署名キー（keystore）が作られる。**必ず安全な場所に保管**（無くすと更新できなくなります）。
3. 生成物の assetlinks.json の内容を、公開サイトの `.well-known/assetlinks.json` に置く。
   これが無いと、アプリ上部にブラウザのバーが出ます。
4. Google Play Console（https://play.google.com/console）で開発者アカウントを登録（25ドル、1回のみ）。
5. 新しいアプリを作成し、AABをアップロード。以下を用意：
   - アイコン 512x512（icons/icon-512.png が使えます）
   - フィーチャーグラフィック 1024x500
   - スクリーンショット（スマホ画面、2枚以上）
   - 短い説明（80字以内）、詳しい説明
   - プライバシーポリシーのURL（…/privacy.html）
6. 「データセーフティ」: データの収集・共有は「なし」（端末内のみ保存、外部送信なし）と申告。
7. コンテンツのレーティング、ターゲット年齢、広告の有無（なし）を回答。
8. 個人アカウントは、公開前にクローズドテスト（目安: 12人以上のテスターで14日間）が必要な場合があります。
   条件はGoogleが随時変更するので、Play Console の案内で最新を確認してください。

## 注意
- 健康データを扱うので、説明文で「診断・治療を目的としない」旨を書いておくと安全です（privacy.htmlにも記載済み）。
- アプリを更新するときは sw.js の VERSION の数字を上げてください（古いキャッシュが残らないように）。
